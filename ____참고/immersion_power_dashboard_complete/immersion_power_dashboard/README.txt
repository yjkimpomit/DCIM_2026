액침냉각 POWER 모니터링 차트 시안 (3개 카드)

사용법: index.html을 브라우저에서 열면 됩니다.
Chart.js 4.5.1 공식 UMD CDN을 사용합니다.
내부망에서 CDN 접속이 불가해도 Canvas 대체 렌더링으로 동일한 차트가 나타납니다.

유지한 데이터
- TOTAL POWER: 5.5 kW / 최대 55.0, PUE 1.82, TANK INLET 31.1°C, SETPOINT TEMP 48.0°C
- SYSTEM POWER: 0.1 kW / 최대 5.0, TANK TEMP 30.9°C, TANK OUTLET 31.7°C, INVERTER SETUP 30.9°C
- SERVER POWER: 8.3 kW / 최대 50.0, TANK INLET 31.1°C, PRESSURE 0.17 bar, ALARM 12건

주의: 실측 예시값을 원본 시안 그대로 사용했습니다. TOTAL과 SERVER 전력 간 관계는 확인이 필요합니다.
